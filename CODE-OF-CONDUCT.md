# CODE OF CONDUCT

## OUR PLEDGE
We commit to fostering an open, welcoming, and respectful environment for all
contributors and users of VMDB_OSS. The project encourages collaboration,
learning, and professional growth.

## OUR STANDARDS

Examples of positive behavior include:
- Using respectful and inclusive language
- Offering constructive technical feedback
- Being open to different approaches
- Accepting responsibility for mistakes
- Helping others understand SQL and database concepts

Unacceptable behavior includes:
- Harassment, abuse, or personal attacks
- Discriminatory or degrading comments
- Public or private intimidation
- Deliberate disruption of discussions or development
- Sharing malicious SQL or vulnerability exploits

## PROJECT MAINTAINER RESPONSIBILITIES
The maintainer is responsible for:
- Reviewing contributions fairly
- Enforcing the Code of Conduct
- Removing inappropriate content
- Banning repeat offenders, if required

## SCOPE
This Code of Conduct applies to:
- GitHub issues and discussions
- Pull requests and review comments
- Documentation and contribution spaces
- Any interaction related to the project
